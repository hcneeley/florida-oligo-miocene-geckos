# Florida Oligo-Miocene Geckos — Accessible Poster

This site is an accessible web version of the research poster *Geckos from the Late Oligocene and Early Miocene of Peninsular Florida*. It presents the same scientific content—introduction, methods, results, fossils, conclusion, and references—in a format that works better for screen readers, keyboard users, and visitors who need adjustable display options.

## Why this site exists

Conference posters are hard to use for many people: dense layouts, small text, and graphics without text alternatives. This page rebuilds the poster as a clear, scrollable document so the research can be read, listened to, and navigated without relying on the PDF alone.

## Accessibility features

- **Listen controls** — built-in speech (Web Speech API) for the full page or individual sections (`Alt+R` / `Alt+S`)
- **Figure captions and long descriptions** — text alternatives for maps, cladograms, and anatomical plates
- **Display options** — larger/smaller text, reset zoom, high contrast, and colorblind simulation filters
- **Keyboard-friendly navigation** — skip link, section menu, and visible focus styles
- **Semantic structure** — headings, landmarks, and labeled controls for assistive technology
